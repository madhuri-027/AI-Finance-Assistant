# 💰 AI Finance Assistant

An intelligent web-based finance management application built using **Python and Flask**. It helps users manage their income, expenses, budgets, recurring transactions, and savings goals through a simple and user-friendly dashboard.

## 🚀 Features

- **User Authentication** – Secure user registration and login.
- **Dashboard** – View your financial overview in one place.
- **Transaction Management** – Add and manage income and expenses.
- **Budget Management** – Create and monitor monthly budgets.
- **Recurring Transactions** – Track regular income and expenses.
- **Savings Goals** – Set financial goals and monitor progress.
- **AI Financial Insights** – View financial insights.
- **AI Chatbot** – Interact with the finance assistant.
- **Analytics** – Visualize financial information using charts.
- **Data Export** – Export financial records.
- **PDF Reports** – Generate and download financial reports.

🎯 Project Objective

The main objective of this project is to develop a centralized financial management platform that makes it easier for users to monitor their financial activities, manage budgets, track savings goals, and understand their spending patterns.
